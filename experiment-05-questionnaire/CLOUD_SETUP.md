# 云开发选做配置
当前使用工具生成的测试 AppID，本地服务功能可以运行；云功能待真实 AppID 和环境 ID 配置与验证。
1. 在 project.config.json 填入本人已注册的小程序 AppID，打开云开发并建立环境。
2. 建立 UserData 集合。直连演示模式使用“仅创建者可读写”权限；姓名只是同一用户内的查询字段，不是授权依据。
3. 在 miniprogram/config.js 设置 cloudEnv，将 storageMode 改为 cloud-direct 或 cloud-function。
4. 直连模式保留学校要求的查询、新增、更新流程。云函数模式使用 OPENID 为记录ID，避免不同用户同名覆盖和并发重复记录。
5. 在 cloud/upsertUserData 上右键“创建并部署：云端安装依赖”。云函数模式数据库权限建议仅云函数可读写。
6. 使用同一微信账号连续提交两次，检查新增与更新记录；不同账号不得覆盖记录。保存数据库和云函数截图。
7. 缺少环境时不要切换模式。云端异常会显示失败，不会被本地提交成功掩盖。
